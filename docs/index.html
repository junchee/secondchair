secondchair 설치 안내

회의를 번역하고, 요약하고, 영어로 대신 말해 주는 프로그램. 천천히 한 단계씩 따라 하세요.

※ 배포 전에 이 파일 맨 아래 const REPO의 OWNER를 GitHub 이름으로 바꾸세요. (설치 명령의 주소에 들어갑니다)

시작하기 전에

설치에는 30분 정도 걸립니다. 대부분은 기다리는 시간입니다. 아래가 준비되었는지 확인하세요.

  • Mac이어야 하고, 2020년 11월 이후에 나온 Apple 칩(M1 이상)이어야 합니다.
    화면 왼쪽 위 ＞ 이 Mac에 관하여 ＞ "칩"에 Apple M1, M2…라고 적혀 있으면 됩니다.
  • 인터넷 연결 (모두 합쳐 약 3GB를 내려받습니다)
  • Mac을 켤 때 쓰는 암호 (중간에 몇 번 묻습니다)
  • 이어폰 (회의 중에는 이어폰을 끼는 것이 가장 좋습니다)
꼭 알아 두세요 이 프로그램은 회의 소리를 글자로 바꿉니다. 회의를 시작할 때 참석자에게 "전사하고 있다"고 알려 주세요. 음성은 내 Mac 안에서만 처리되고, 번역과 요약을 위해 글자만 인터넷으로 보냅니다.

터미널 열기

터미널은 Mac에 처음부터 들어 있는, 글자로 명령을 내리는 프로그램입니다. 무섭지 않습니다. 이 안내에 있는 명령을 그대로 붙여 넣기만 하면 됩니다.

  1. ⌘ 와 Space 를 함께 누릅니다. 화면 가운데에 검색창이 뜹니다.
  2. 터미널 이라고 입력합니다.
  3. Enter 를 누릅니다.
이렇게 보이면 성공 흰색 또는 검은색 창이 열리고, 맨 윗줄 끝에 % 모양 기호가 깜빡입니다.

이 창은 설치가 모두 끝날 때까지 닫지 마세요.

설치 명령 붙여 넣기

아래 상자의 복사를 누르고, 터미널 창을 한 번 클릭한 다음 ⌘ + V (붙여 넣기), 이어서 Enter 를 누르세요.


    
그러면 필요한 것을 알아서 설치합니다. 중간에 다음 일이 생길 수 있습니다.

    

      "암호(Password)"를 물어요
      
Mac을 켤 때 쓰는 암호를 입력하고 Enter. 입력해도 화면에는 아무것도 나타나지 않는 것이 정상입니다. 그냥 입력하세요.

    

    

      "명령줄 개발자 도구를 설치하시겠습니까?" 창이 떠요
      
설치를 누르고 끝날 때까지 기다리세요(몇 분). 끝나면 터미널에 같은 명령을 다시 붙여 넣으세요. 이미 설치된 것은 건너뛰니 처음부터 다시 해도 괜찮습니다.

    

    

      "Press RETURN/ENTER to continue"라고 나와요
      
Enter 를 누르세요. Homebrew라는 설치 도우미를 처음 깔 때 나오는 안내입니다.

    

    

      한참 동안 글자만 계속 나와요
      
정상입니다. 5~15분 걸릴 수 있습니다. 창이 멈춘 것처럼 보여도 닫지 마세요.

    

    

      중간에 "멈췄습니다"라고 나와요
      
빨간 글씨의 설명을 읽고, 인터넷 연결을 확인한 뒤 같은 명령을 다시 붙여 넣으세요. 그래도 안 되면 터미널의 글자를 복사해서 알려 주세요.

    

    
이렇게 보이면 성공
      마지막에 초록색으로 "설치가 끝났습니다."라고 나옵니다.

  


  
  

    
Mac 재시동

    
소리 드라이버를 처음 설치했다면 Mac을 한 번 재시동해야 합니다. 설치가 끝났을 때 "지금 Mac을 재시동하세요"라는 안내가 나왔다면 이 단계가 필요합니다.

    
    
      
  1. 화면 왼쪽 위  메뉴를 누릅니다.
    2. 
      
  2. 재시동… 을 선택하고, 한 번 더 재시동을 누릅니다.
    3. 
    

    
그런 안내가 나오지 않았다면 이 단계는 건너뛰세요.

    
재시동이 끝나면 바탕화면에 "secondchair 시작" 아이콘이 보입니다. 이 아이콘이 앞으로 프로그램을 시작하는 방법입니다.

  


  
  

    
번역 키 받기 (번역·요약을 쓰려면)

    
글자를 받아 적는 것은 키 없이도 됩니다. 번역, 요약, 질문, 영어로 말하기를 쓰려면 OpenRouter라는 서비스의 "키"가 필요합니다. 내 계정으로 쓰고, 쓴 만큼만 냅니다(회의 한 시간에 몇십 원 정도).

    
    
      
  1. 인터넷 주소창에 openrouter.ai 를 열고 가입합니다 (Google 계정으로 가능).
    2. 
      
  2. 오른쪽 위 메뉴 ＞ Credits 에서 5달러 정도를 충전합니다.
    3. 
      
  3. Keys ＞ Create Key 를 눌러 이름을 아무거나 짓고 만듭니다.
    4. 
      
  4. 나온 sk-or-… 로 시작하는 긴 글자를 복사합니다. 이 창을 닫으면 다시 볼 수 없습니다.
    5. 
    

    
설치할 때 키를 물어서 이미 넣었다면 이 단계는 끝났습니다. 나중에 넣고 싶다면 아래 칸에 붙여 넣으세요. 터미널에 넣을 명령이 만들어집니다.

    

    
이 키는 이 페이지 안에서만 쓰이고 어디로도 보내지지 않습니다.

    

    
위 명령을 터미널에 붙여 넣고 Enter. 그다음 터미널을 닫았다가 다시 시작하면 적용됩니다.

  


  
  

    
처음 실행하기

    
    
      
  1. 바탕화면의 secondchair 시작 아이콘을 두 번 클릭합니다.
    2. 
      
  2. "확인되지 않은 개발자" 같은 경고가 나오면: 시스템 설정 ＞ 개인정보 보호 및 보안 아래쪽의 "그래도 열기" 를 누르세요.
    3. 
      
  3. "터미널이 마이크에 접근하려고 합니다" 창이 나오면 허용 을 누릅니다.
    4. 
      
  4. 처음 한 번은 음성 인식 모델(약 0.5GB)을 내려받습니다. 몇 분 걸립니다.
    5. 
    

    
이렇게 보이면 성공
      인터넷 브라우저가 열리고 secondchair 화면이 나옵니다. 위쪽에 "Output: …", "Mic: on" 표시가 보입니다.
      (브라우저가 열리지 않으면 주소창에 127.0.0.1:8765 를 입력하세요.)

    
이어폰을 끼고 아무 영상이나 틀어 보세요. 몇 초 안에 영어 줄과 한국어 번역이 나타납니다.

  


  
  

    
회의에서 쓰기

    
1. 이어폰을 끼고, secondchair를 시작한 다음, Zoom이나 Teams를 평소처럼 엽니다. 상대방의 말이 화면에 글자와 번역으로 나옵니다. 따로 설정할 것은 없습니다.

    
2. 내가 영어로 말해야 할 때 (통역 기능)

    
    
      
  1. Zoom ＞ 설정 ＞ 오디오 ＞ 마이크를 BlackHole 16ch 로 바꿉니다. (Teams는 설정 ＞ 장치 ＞ 마이크)
    2. 
      
  2. secondchair 화면 위쪽에서 Interpret 를 누릅니다.
    3. 
      
  3. 한국어로 말합니다. 아래 칸에 영어가 나타납니다.
    4. 
      
  4. 맞으면 "오케이" 라고 말하거나 Speak 를 누릅니다. 영어 음성이 회의로 나갑니다. 내 이어폰에도 작게 들립니다.
    5. 
      
  5. 틀렸으면 "다시" 라고 하거나 한국어로 다시 말합니다.
    6. 
    

    
3. 말하지 않고 글로: 맨 아래 칸에 한국어를 입력하면 영어가 나옵니다. 소리 내어 읽거나 Speak를 누릅니다.

    
4. 궁금한 것 묻기: 아래 칸에서 Ask 를 고르거나 ? 로 시작해서 "방금 무슨 얘기야?"처럼 물어보세요. 오른쪽에 답이 나옵니다.

    
5. 요약: 위쪽 Summary 를 누르면 지금까지의 요약이 오른쪽에 나옵니다. 회의는 계속됩니다.

    
회의가 끝나면
      위쪽 빨간 Stop 버튼을 누르세요. 요약을 만들고 대화 기록을 저장한 뒤 소리 설정을 원래대로 돌려 놓습니다. 브라우저 창만 닫으면 프로그램은 계속 켜져 있습니다.

  


  
  

    
문제가 생기면

    

      상대방 말이 화면에 안 나와요
      
회의가 아직 소리를 내지 않는 중일 수 있습니다. 소리가 나는데도 안 나오면 Stop을 누르고 아이콘을 다시 눌러 보세요. 그래도 안 되면 Mac을 재시동하세요.

    

    

      "BlackHole 16ch is not installed"라고 나와요
      
재시동이 안 된 것입니다. Mac을 재시동하세요. 그래도 안 되면 3단계의 설치 명령을 다시 붙여 넣으세요.

    

    

      회의가 끝났는데 Mac에서 소리가 안 나요
      
프로그램이 비정상으로 꺼졌을 때입니다. 아이콘을 눌러 프로그램을 한 번 켰다가 Stop으로 끄면 원래대로 돌아옵니다. 또는 시스템 설정 ＞ 소리 ＞ 출력에서 쓰던 장치(스피커, 이어폰)를 직접 고르세요.

    

    

      내 목소리가 화면에 안 나와요 (Mic: off)
      
스피커로 듣고 있으면 마이크가 꺼집니다(회의 소리가 마이크로 다시 들어가기 때문입니다). 이어폰을 끼면 자동으로 켜집니다.

    

    

      번역이 안 나와요
      
5단계의 번역 키가 들어 있는지, OpenRouter에 충전한 금액이 남아 있는지 확인하세요.

    

    

      프로그램을 최신으로 바꾸고 싶어요
      
3단계의 설치 명령을 다시 붙여 넣으세요. 이미 설치된 것은 건너뛰고 프로그램만 최신으로 맞춥니다.

    

    

      완전히 지우고 싶어요
      
바탕화면의 "secondchair 시작" 아이콘과, 홈 폴더의 secondchair 폴더를 휴지통에 넣으세요. 대화 기록은 그 폴더 안의 transcripts 폴더에 있으니 필요하면 먼저 옮겨 두세요.

    

    
끝! 수고하셨습니다. 이제 회의에서 써 보세요.
