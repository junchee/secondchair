## Decisions (secondchair)
- v1 is a Python backend with a browser UI on localhost; later a native Swift app (process tap, overlay hidden from screen share, menu bar). Path: browser version (venv + BlackHole) -> Python bundled in a .app -> Swift app without BlackHole.
- Audio: the user's audio settings stay theirs. While a meeting runs, `native/route` (Swift, built by `swiftc` on first use) makes a temporary output "secondchair (device)" = real output + BlackHole 2ch as the default output, follows device changes, and restores/deletes it on exit (also if the parent dies). Target design without any device change (Core Audio process tap): `docs/audio_routing.md` (`native/audiotap.swift` is an untested spike).
- Speech to text: local Whisper (Apple silicon, `mlx-whisper`). Translation, summary, Ask: Qwen through OpenRouter, key in `OPENROUTER_API_KEY`, zero data retention enforced per request (`provider: {zdr: true, data_collection: deny}`; Alibaba-hosted Qwen flash models are refused under it).
- Meetings are mostly English; translation per line is on by default; Jun reads the English he needs himself (the computer voice is rare and sits in a small Beta footer). Participants are told the meeting is transcribed.

- **Voices:** Kokoro-82M through `mlx-audio` 0.6.1 (`misaki[en]` installs only with `--only-binary=:all:`); macOS `say` is not used any more. Pool = 7 British + 9 American male voices; `bm_george` is out (Jun: not clear enough for practice); explaining voice default `bm_lewis`; Settings lets Jun tick one voice or several (random among them).
- **Reading a sentence:** the browser records (Web Audio, 16-bit wav) and posts to 127.0.0.1 only. Two judges, set in Settings (both / sound only / Whisper only): the **sound judge** (`phoneme.py`, `facebook/wav2vec2-xlsr-53-espeak-cv-ft`, 1.26 GB, GPU fp16) is the main one; **Whisper-small** (`judge.py`) gives the "들린 말" row and the live "듣는 중" text and is optional. Marks: ok / doubt / wrong / missed. Wrong = a consonant heard as another consonant with confidence >= 0.5; doubt = only a vowel differs, a sound is missing, the model was unsure, or only voicing differs (s/z, sh/zh, th/ð, ch/j anywhere; final p/b, t/d, k/g); small function words are never wrong; a reading that matches under half the words is "incomplete" (shown, not saved; for one word, only "nothing heard" is incomplete). **Target accent: British by default** (Settings; the sound judge builds expected sounds with its own espeak backend per accent; never use the HF tokenizer's `phonemize(text, lang)` for that, it keeps stale state; British/American spellings of one vowel count as equal; an extra r is ignored for British).
- **Screen:** mic level bar, timer and a hint when little or no sound arrives; microphone name; the newest try right under the original sentence, older tries below, a foldable "내가 아는 것" summary with the match percentage per try (ok 1, doubt 0.5) and its trend; the sentence grid shows the script word and Whisper's heard word (no sound symbols); tapping a word shows the expected and heard sounds with a Korean note, right sound / own sound / alternate, "이 단어 연습하기". **Word drill:** the word is read inside a short phrase (now one word each side), each reading judged, 3 in a row passes, own sound replayable, the review list is not touched (`drill=1`).
- **Microphone:** `openAudio()` skips virtual microphones (BlackHole, Teams, Camo ... : BlackHole 16ch is silent unless secondchair runs); Settings has a microphone list and a 5-second sound check; a recording with no sound is not judged.
- **Speed and memory (this Mac has 8 GB):** one worker thread for all MLX work (`worker.py`), caches cleared after each job, MLX cache 200 MB: server about 2.1 GB, both judges about 2.5 s per reading, the sound judge alone 0.2 s (Whisper alone about 1.2 s with word times, 0.75 s without); first start loads the models in 15-20 s.
- **Privacy:** audio never leaves the Mac (only model downloads and update checks reach Hugging Face); the last 30 readings stay in memory only; text (script, review) is saved locally. yourAccent does not use OpenRouter.
- **What the judges can and cannot do:** Whisper turns a slightly wrong word into the right one, so it can hide mistakes; the sound judge is better but also leans toward the plausible reading in a long sentence, is unreliable on a word read alone (word-initial s/sh/th), and is weak on vowels. Jun tried it on his own voice ("much better"); R/L, th/s and V/B mistakes by computer voices were caught, vowel cases ("older" heard as "all the") are only "doubt".

## Design (2026-11-05, Jun OK'd to record): fit Anne to the Mac it runs on
Why: on this 8 GB M1 swap was 10 GB used and transcription was 3-8x slower (disk free fell from 41 to 21 GB because swap lives on the disk); a family or commercial Mac may have less or more.
1. **At first start (and at install):** read chip, RAM and free disk; pick a tier. 8 GB or less: whisper-small only, drafts off or slow, mic button off by default. 16 GB: small, drafts on. 24 GB and more: turbo allowed. Download only the model that tier needs.
2. **While running:** if swap grows or transcription falls behind speech (whisper seconds > speech seconds for several lines), turn drafts off / lengthen the interval and tell the user "the computer is busy, some features are reduced; close other apps"; turn them on again when it eases.
3. **Settings > 성능:** 자동 (recommended) / 가볍게 / 정확하게; the Tuning tab stays a developer tool, hidden in a release.
4. Optional later: cloud transcription as an explicit choice (audio leaves the Mac; off by default). Biggest lever: the Swift app without Python/torch (see Installing).
Measured on 2026-11-05: turbo needs about 1.5 GB disk and 2-2.5 GB RAM and ran about 5 s per call on this Mac (small about 1 s): not for 8 GB.
